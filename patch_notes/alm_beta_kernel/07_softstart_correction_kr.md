## 1. 문제 (06 §6b)

램프 게이팅(06)은 램프 **중** 진입 창을 닫았지만, 25rev 본런에서
블레이드 2가 **램프 종료 직후 과도에서 포획**됐다(mk63 −5.6° 고착).
잔여 진입로: 게이트가 램프 종료 시점에 정확히 1.0에 도달하는데, 그
순간 유동은 아직 풀-포스 평형에 못 미침(램프 내내 ramp·F만 받아 유도
속도장이 지연) → 보정이 유동 대비 일시 과대 → R2′fix/25rev 공통으로
관측된 결정론적 스윙(+2.6/−9.5/−4.5/−7.3 @1rev) → 쌍안정 포획.

## 2. 수정

`eps_correction.soft_start` (기본 **2.0**, 하한 1.0):

```python
_w_win = self._eps_corr_soft * ramp_steps
if ramp_steps > 0 and (step+1) < _w_win:
    w_corr *= (step+1) / _w_win
```

- **불변식**: 창 ≥ ramp이므로 보정 팩터 ≤ 힘 램프 팩터 — 보정이 침적
  력의 정합 수준을 절대 초과하지 않음(06의 원칙 유지·강화).
- soft=1.0 = 06과 동일(게이트가 힘 램프를 정확히 미러). 기본 2.0은
  램프 종료 후 한 램프 분량의 시간 동안 아래에서 천천히 전강도 접근.
- 정상상태(step ≥ 창)에서는 분기 미실행 = 수렴 상태 불변. config
  무수정으로 기존 case4′/case4 config 그대로 재런 가능.
- bool-형 eps_correction 경로 대비 __init__ 기본값 병설.
