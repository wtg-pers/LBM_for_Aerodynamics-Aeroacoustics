# β Kernel 03 — Wendland 보정 커널 닫힌형 유도 (2026-07-16, 완료·검증)

01_design §5.2 전략 (a)의 수행: **커널과 같은 η에서 보정을 유도**한다.
결과는 `alm_kernel.py::deficit_K`의 wendland 분기 + G-β2 게이트.
(작업항목명 "02_correction" = 이 문서; 파일 번호는 02_gbeta0 다음이라 03.)

## 1. 대상과 규약

코드의 보정 구조(Dağ Eq.17 / `influence_matrix` / `_viscous_core_correction`):

    w_i = +(1/4π) Σ_j Γw_j · K(d_ij)/d_ij

K(d)는 **뭉개진 직선 trailed 와류의 유도속도 결손 인자** = 1 − Γ_enc(d)/Γ.
Gaussian이면 K = exp(−d²/ε²) (Lamb–Oseen). 반무한 필라멘트여도 로터 평면
(필라멘트 시작 평면)에서는 직선 코어의 거울대칭으로 무한 라인의 정확히
절반이 유도되므로, 무한-라인 결손 인자를 그대로 쓰는 기존 규약이 성립한다.

유도 체인: 3D 커널 η₃를 필라멘트 축(z)으로 적분 → 2D 사영 코어
η₂(ρ) → Stokes 정리로 u_θ·2πd = Γ_enc(d) → K = 1 − Γ_enc/Γ.

## 2. 사영 적분

η₃(r) = 21/(2πR³)·ψ(r/R), ψ(q) = (1−q)⁴(4q+1) = 1 −10q² +20q³ −15q⁴ +4q⁵,
R = R_s = √7.5·ε (ε-등가 support). 무차원 s = ρ/R, t = z/R,
a ≡ √(1−s²), L ≡ ln((1+a)/s):

    η₂(ρ) = (21/(πR²)) I(s),   I(s) = ∫₀^a ψ(√(s²+t²)) dt

짝수 멱은 초등적분(T₀=a, T₂=s²a+a³/3, T₄=s⁴a+(2/3)s²a³+a⁵/5), 홀수 멱은
환원공식 ∫(t²+s²)^{n/2}dt = [t(t²+s²)^{n/2} + n s²∫(t²+s²)^{(n−2)/2}]/(n+1)
과 asinh(a/s) = L (∵√(a²/s²+1) = 1/s)로:

    J₃ = a/4 + (3/8)s²a + (3/8)s⁴L
    J₅ = a/6 + (5/24)s²a + (5/16)s⁴a + (5/16)s⁶L

조립(a³=a(1−s²), a⁵=a(1−s²)² 전개):

    I(s) = a[1/3 − (7/3)s² − (27/4)s⁴] + [(15/2)s⁴ + (5/4)s⁶]·L

검산: I(0)=1/3=∫₀¹ψ ✓, s=0.5 수치적분과 일치 ✓.

## 3. 누적 순환

F(x) = Γ_enc/Γ = 42∫₀^x s·I(s) ds (42 = 2π·21/π). **핵심 단순화:
dL/ds = −1/(s·a)** (로그 도함수가 대수식으로 닫힘) → 부분적분으로 L-항이
전부 초등화된다:

    ∫₀^x sⁿL ds = xⁿ⁺¹L/(n+1) + (1/(n+1))∫₀^x sⁿ/a ds

u = 1−s² 치환으로 나머지 전부 계산, 상수부는 정확히 1/42로 수렴
(F(1) = 42·(1/42) = 1 = **총순환 보존**, 유도 전체의 자기검산).

## 4. 결과

    x = |d|/R_s ∈ [0,1],  a = √(1−x²),  L = ln((1+a)/x)

    ┌──────────────────────────────────────────────────────────────┐
    │ K_W(x) = (1/16)·[ a(945 − 2625a² + 2359a⁴ − 663a⁶)          │
    │                   − 105·x⁶(8 + x²)·L ]                       │
    │ K_W = 0  (x ≥ 1)                                             │
    └──────────────────────────────────────────────────────────────┘

- K(0) = (945−2625+2359−663)/16 = 16/16 = **1 정확히**.
- K(1) = 0 (a=0, L=0) — support 경계에서 매끄럽게 0.
- **compact의 물리적 의미가 보정에도 그대로**: support 밖 원거리장은
  정확하므로 보정이 작동할 영역이 x<1로 국한된다 (Gaussian은 전 반경).

## 6. 물리 비교 (ε-등가, 같은 물리 거리에서)

| 1.37 | 0.157 | 0.153 |
| 2.0 | 0.0094 | 0.0183 |
| ≥2.74 (=R_s) | **0 정확히** | 5.5e-4 |

d ≲ 1.4ε에서 두 커널의 결손이 거의 같고(2차 모멘트 일치의 결과), 바깥은
wendland가 빠르게·정확하게 닫힌다 — "형태만 바꾼" 비교의 전제(01_design
§3 ε-등가)가 보정 수준에서도 성립함을 보여준다.

## 7. 구현/영향

- `deficit_K` wendland 분기 구현(클램프로 x=0/x≥1 안전) — 이로써
  **β 물리 실험의 차단이 해제**됨 ("opt" 타깃 = 두 폭의 K 차이도 자동
  지원). straight-Kleine의 `influence_matrix`도 같은 K를 씀(연산자 공유).
- G-β0 게이트 재실행 PASS (기존 클레임 무영향).
